# 폰 런처 (scrcpy GUI)

USB로 연결한 안드로이드 폰을 PC에서 녹스/블루스택처럼 쓰는 런처예요.
앱 아이콘을 클릭하면 PC 창에서 바로 실행되고, **폰 화면은 꺼진 상태**로 유지돼요.

## 기능
- 폰에 설치된 앱을 아이콘 그리드로 표시, 검색, 즐겨찾기 (우클릭 → 즐겨찾기 추가)
- 클릭 한 번으로 앱 실행. 폰 화면 창이 열려 있으면 그 안에서, 없으면 창을 열면서 실행
- 폰 화면 끄고 사용 (`--turn-screen-off`), 연결 중 절전 방지 (`--stay-awake`)
- 오른쪽 사이드바: 뒤로 / 홈 / 최근 앱 / 볼륨 +·- / 음소거 / 회전 / 스크린샷 / 알림창 / 전원
- 폰 화면 창을 런처 바로 오른쪽에 붙여서 에뮬레이터처럼 배치
- (옵션) 앱마다 새 창: 가상 디스플레이로 앱을 각각 다른 창에 띄우기 (Android 10+ 필요)
- 소리도 PC로 전달 (Android 11+), 해상도·FPS·화질 설정

## 최적화 · 발열
- 폰 화면을 끈 채로 쓰기 때문에, 화면을 켜고 쓸 때보다 배터리와 발열 부담이 적어요.
- scrcpy 5는 PC 그래픽카드로 영상을 풀어서 PC CPU를 적게 써요.
- 위쪽 줄에 **배터리 %, 충전 상태, 폰 온도**가 30초마다 표시돼요. 40°C를 넘으면 주황색, 45°C를 넘으면 빨간색으로 경고해요.
- 폰이 뜨거우면 설정 탭에서 **절전 모드**를 켜세요. 화질을 1024px · 30fps · 4Mbps로 낮춰서 폰의 인코딩 부담을 줄여줘요. 다음에 여는 창부터 적용돼요.

## 앱 아이콘
앱 목록에는 폰에 있는 진짜 아이콘이 보여요. 처음 한 번은 폰에서 아이콘을 가져오느라 몇 초 걸리고, 그다음부터는 PC에 저장해둔 걸 써요 (`%APPDATA%\PhoneLauncher\icons`, "설정 저장 안 함"이면 저장 안 함). 가져오지 못한 앱은 첫 글자 아이콘으로 나와요.

## 준비물 (한 번만)
1. **scrcpy 다운로드**: https://github.com/Genymobile/scrcpy/releases 에서 최신 Windows용 zip(`scrcpy-win64-v5.x.zip` 등, 3.0 이상이면 OK) 받기
   → 압축을 풀어 폴더 이름을 `scrcpy` 로 바꾸고 이 폴더(`phone_launcher.py` 옆)에 넣기.
   (다른 곳에 두면 런처의 **설정 탭 → scrcpy.exe 위치**에서 지정하면 돼요. adb는 scrcpy 안에 들어 있어요.)
2. **파이썬 3.8 이상** (exe로 만들어 쓰면 실행할 때는 파이썬이 필요 없어요). 런처는 자기 폴더 안의 `.venv` 가상환경에 PySide6를 설치하므로 기존 파이썬 프로그램에는 영향이 없어요.
3. **폰에서 USB 디버깅 켜기**
   - 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호 7번 탭** (개발자 모드 켜짐)
   - 설정 → 개발자 옵션 → **USB 디버깅** 켜기
   - 삼성이면 개발자 옵션의 **"USB 디버깅(보안 설정)"** 이 있으면 같이 켜야 클릭/터치가 돼요 (샤오미도 비슷한 항목 있음)
   - USB 케이블 연결 → 폰에 뜨는 **"USB 디버깅 허용"** 팝업에서 *항상 허용* 체크 후 확인

폴더 구성 예시:
```
scrcpy-launcher\
  phone_launcher.py
  setup.bat  run.bat  build_exe.bat
  scrcpy\  (scrcpy.exe, adb.exe ...)
```

## 무선(Wi-Fi)으로 연결하기 — 케이블 없이
PC가 유선이고 폰이 Wi-Fi여도 **같은 공유기**면 돼요. Android 11 이상 필요.
1. 폰: 설정 → 개발자 옵션 → **무선 디버깅** 켜기 (삼성: 개발자 옵션 목록 중간, *USB 디버깅* 아래쪽에 있어요. 개발자 옵션이 없으면 *설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭*)
2. 무선 디버깅 글자를 눌러 들어가서 **페어링 코드로 기기 페어링** 누르기 → IP:포트와 6자리 코드가 나와요
3. 런처 위쪽 **📶 버튼** → ① 에 페어링 IP:포트·코드 입력 → *페어링*
4. ② 에 무선 디버깅 화면 위쪽의 **IP 주소 및 포트** (페어링 포트와 달라요) → *연결* (자동 찾기로 채워지는 경우가 많아요)
5. 다음부터는 런처를 켜면 자동으로 다시 연결돼요. 폰에서 무선 디버깅만 켜두면 돼요.

무선 연결에서도 폰 화면은 꺼진 채로 쓸 수 있어요. 끊기거나 느리면 설정 탭에서 화질을 4~6 Mbps, 해상도를 1280 정도로 낮춰보세요.
*참고: 폰이 Wi-Fi를 바꾸거나 무선 디버깅을 껐다 켜면 포트가 바뀌어서 ② 연결을 다시 해야 할 수 있어요 (페어링은 다시 안 해도 돼요).*

## 실행
1. `setup.bat` 더블클릭 (처음 한 번, PySide6 설치)
2. `run.bat` 더블클릭
3. 위쪽에 폰 이름이 뜨면 앱 아이콘 클릭 → 실행!

### 가장 쉬운 방법: 완성된 exe 받기
[Releases](https://github.com/kcrownclown84-ai/scrcpy_launcher/releases/latest)에서 `PhoneLauncher.exe` 하나만 받아 실행하세요. scrcpy와 adb가 들어 있어서 따로 설치할 게 없어요 (폰 USB 디버깅만 켜면 됨).
같은 폴더에 `scrcpy` 폴더를 두면 내장 버전 대신 그걸 써요 (scrcpy만 최신으로 바꾸고 싶을 때).

### exe로 직접 만들기
- **내 PC에서**: `build_exe.bat` 더블클릭 → `dist\PhoneLauncher.exe` 생성 (setup.bat 없이 바로 돼요. 파이썬 3.8도 OK). exe 옆에 `scrcpy` 폴더를 두면 끝. 이후엔 파이썬 없이 exe만으로 실행돼요.
- **GitHub에서 자동으로**: 이 폴더를 GitHub 저장소에 올리면 `.github/workflows/build-exe.yml` 이 Windows에서 exe를 만들어 Actions 탭의 *Artifacts* 에 올려줘요.

## 사용 팁
- **우클릭 메뉴**: 새 창으로 실행 / 처음부터 다시 실행 / 강제 종료 / 즐겨찾기
- 폰 화면 창 단축키: `Alt+O` 폰 화면 끄기, `Alt+Shift+O` 다시 켜기, `Alt+F` 전체화면, `Alt+R` 회전, 마우스 우클릭 = 뒤로
- 키보드로 한글 입력이 안 되면 폰의 키보드 앱에서 입력하거나, 클립보드에 복사 후 `Ctrl+V` 로 붙여넣기 하세요.
- 스크린샷은 `사진\PhoneLauncher` 폴더에 저장돼요.

## 자주 막히는 곳
| 증상 | 해결 |
|---|---|
| "연결된 폰 없음" | 케이블이 충전 전용인지 확인, 폰 알림에서 USB 모드를 *파일 전송*으로, USB 디버깅 다시 켜기 |
| `unauthorized` 표시 | 폰 화면을 켜서 USB 디버깅 허용 팝업 누르기 |
| 화면은 보이는데 클릭이 안 됨 | 개발자 옵션의 *USB 디버깅(보안 설정)* 켜기 |
| 폰 화면이 다시 켜짐 | 폰 전원 버튼을 누르면 켜져요. 창에서 `Alt+O` 로 다시 끄기 |
| 잠금화면이 보임 | 창에서 그대로 PIN/패턴 입력해서 풀면 돼요 |
| "새 창으로" 실행이 안 됨 | Android 10 이상 + scrcpy 3.0 이상 필요. 일부 기종은 잠금 상태에서 가상 디스플레이가 검게 나와요 → 기본 모드 사용 |
| 앱 이름 대신 영어 패키지명 | scrcpy 2.1 미만이면 그래요. 최신 scrcpy로 바꾸세요 |

## PC에 남는 파일
- **설정 파일**: `%APPDATA%\PhoneLauncher\config.json`. 설정을 바꾸거나 즐겨찾기를 추가할 때만 생겨요.
  설정 탭의 **"설정 저장 안 함"** 을 켜면 이 파일을 바로 지우고, 그 뒤로는 아무것도 저장하지 않아요.
  처음부터 아무 파일도 안 남기려면 exe 바로가기 대상 끝에 ` --no-save` 를 붙여서 실행하세요.
- **exe 임시 파일**: 실행 중에만 `%TEMP%\_MEI...` 에 풀렸다가, 런처를 닫으면 자동으로 지워져요.
- **스크린샷**: 📷 버튼을 눌렀을 때만 `사진\PhoneLauncher` 에 저장돼요.
- **adb 인증키** `%USERPROFILE%\.android\`: adb가 만드는 파일이에요. 지우면 다음 연결 때 폰에서 "USB 디버깅 허용"을 다시 눌러야 해요.
